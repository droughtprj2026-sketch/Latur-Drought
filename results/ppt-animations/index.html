    PowerPoint Cartographic Animation Suite¶

    This suite provides high-resolution, presentation-ready GIF animations designed specifically for academic conferences, government stakeholder briefings, and policy presentations.

    1. PowerPoint Integration & Cartographic Standards¶

    All animations are pre-rendered conforming strictly to scientific publishing rules: - Strict Times New Roman typography throughout. - Single upper-right North arrow placed outside feature neatlines without bounding boxes. - Georeferenced scale bar (\(0\text{--}40\text{ km}\)) with physical distance ticks. - Dynamic top timeline progress bar and HUD statistics banner. - Optimized 128-color adaptive palettes ensuring compact file sizes (\(1.0\text{--}11.8\text{ MB}\)) that insert and loop effortlessly in PowerPoint.

    How to Embed in PowerPoint¶

    1. In Microsoft PowerPoint, select the target presentation slide.
    2. Click Insert \(\to\) Pictures \(\to\) This Device...
    3. Select the GIF animation file from output/figures/scientific_suite/09_animations/.
    4. Start Slide Show mode (F5 or Shift + F5). The animation will play and loop automatically.
